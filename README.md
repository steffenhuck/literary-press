# Literary Press (1991–1994)

This repo is a small gallery page for the imprint **Mühlbach | Huck | Wegener**.

## Deploy
1. Push to `main` (already configured).
2. In **Settings → Pages**, set **Source = GitHub Actions** (once).
3. After the Actions run turns green, the site will be live at:
   `https://steffenhuck.github.io/<repo-name>/`

## Images
Images are in `img/` and already optimized for web display.
